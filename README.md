# Hi, I'm Melike 👋

Frontend developer based in Stuttgart, Germany. I have spent over six years building web applications with **React**, **TypeScript**, and **Angular**, and I care about interfaces that are fast, accessible, and easy to maintain.

## What I do

* Build scalable UIs and reusable component libraries
* Work on design systems and documentation with Storybook
* Improve performance, accessibility (WCAG), and responsive behavior
* Manage complex state and async workflows with RxJS, NgRx, and NGXS
* Integrate REST APIs and build small services with Node.js
* Explore AI assisted development and UI for streaming and long running tasks
